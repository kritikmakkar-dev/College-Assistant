# 🎓 AI College Assistant

An AI-powered College Assistant chatbot built using **Flask** and **Google Gemini AI**.

It helps students by answering college-related and general academic questions through a simple and modern chat interface.

---

## ✨ Features

- 🤖 Google Gemini AI Integration
- 💬 Real-time Chat Interface
- 📚 FAQ Support
- 📋 Copy AI Responses
- 💾 Chat History (Browser Storage)
- ✨ Markdown Support
- ⌨️ Typing Animation
- 📱 Responsive UI
- 🔐 Secure API Key using `.env`

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-College-Assistant.git
```

Go to the project folder

```bash
cd AI-College-Assistant
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
